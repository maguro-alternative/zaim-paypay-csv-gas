# zaim-paypay-csv-gas

# ライブラリ
- OAuth1
  - https://github.com/googleworkspace/apps-script-oauth1

 # 使い方
 - https://dev.zaim.net/home でアプリを登録し、「コンシューマID」と「コンシューマシークレット」を控える。
 - `CONSUMER_KEY`と`CONSUMER_SECRET`の部分をそれぞれ「コンシューマID」と「コンシューマシークレット」に書く。
 - run関数を実行し、認可を行う。
 - デプロイのテストをクリックし、出てきたURLをクリックするとcsvをアップロードするページに飛ぶのでそこにアップロード。
